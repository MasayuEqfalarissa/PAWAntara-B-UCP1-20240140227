## Cara Menjalankan Project Secara Lokal

1. Clone Repository
   ```bash
   git clone https://github.com/masayueqfalarissa/PAWAntara-B-UCP1-20240140227.git
   cd PAWAntara-B-UCP1-20240140227

   npm install
3. jalankan server
   npm run dev
4. Akses di Browser
Buka http://localhost:3000 pada browser Anda.
